Tela de Login
Este é um projeto pessoal de uma tela de login desenvolvida para facilitar o acesso a uma aplicação. Esta tela permite que os usuários ingressem com seu nome de usuário e senha para acessar o sistema.


Tecnologias Utilizadas:
HTML5
CSS3

Funcionalidades:
Permite que os usuários insiram seu nome de usuário e senha para fazer login.
Estilizado de forma responsiva para se adaptar a diferentes tamanhos de tela.
Validação de entrada básica: os campos de usuário e senha são obrigatórios.
Botão "Login" para enviar as credenciais e tentar fazer login.
Design atraente e moderno, com cores suaves e uma aparência profissional.
Instruções de Uso
Abra o arquivo index.html em qualquer navegador da web.
Insira seu nome de usuário no campo "Usuário".
Insira sua senha no campo "Senha".
Clique no botão "Login" para enviar suas credenciais.
Se as credenciais estiverem corretas, você será redirecionado para a página inicial do sistema.
